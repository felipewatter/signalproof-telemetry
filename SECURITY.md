# Política de segurança

**Versões suportadas:** a versão estável mais recente da série `0.x` recebe correções de segurança, enquanto possível.

## Relatar vulnerabilidade

**Não crie uma issue pública com detalhes de exploração ou arquivos confidenciais.** Utilize a aba **Security → Report a vulnerability** (Private Vulnerability Reporting), quando habilitada pelo mantenedor do repositório. Caso indisponível, abra uma issue sem detalhes técnicos confidenciais solicitando um canal privado.

Inclua versão, SO, passos de reprodução com dados artificiais e impacto. Não inclua tokens, chaves, IPs internos, logs reais, nomes de clientes ou credenciais.

Não prometemos SLA de resposta nem garantia formal de ausência de vulnerabilidades. Ainda que o programa seja offline, entrada não confiável exige cuidado e isolamento operacional.
