# Contribuição

Obrigado por contribuir. Abra uma issue antes de mudanças de grande porte. Mudanças precisam de testes reproduzíveis, exemplos sintéticos e documentação em português do Brasil (pode acompanhar resumo em inglês).

## Checklist de PR

- [ ] Não remover funcionalidades existentes sem justificativa e aprovação.
- [ ] Executar `python -m pytest -q` e `python -m compileall -q src tests`.
- [ ] Reproduzir a falha corrigida em teste de regressão.
- [ ] Manter formatos de relatórios e exit codes compatíveis, ou atualizar versão/schema.
- [ ] Não inserir credenciais, recibos reais ou configurações de produção.
- [ ] Atualizar README/documentação se comportamento ou política mudar.
- [ ] Conferir funcionamento em Linux, Windows e macOS pelo GitHub Actions.

PRs pequenos e revisáveis são preferíveis. Contribuições são disponibilizadas sob MIT.
